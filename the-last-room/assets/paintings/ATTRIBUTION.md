# Open-access painting sources

The twelve `museum-*.jpg` files are web-sized derivatives of artworks the Art Institute of Chicago API marks as public domain. They are bundled locally so the game works offline. Source metadata and image identifiers were retrieved from the Art Institute of Chicago API; the image derivatives use its documented IIIF endpoint.
