    About the archive & check statuses

    One entry groups related builds of a game. The build selector keeps older versions available. Sizes shown on cards and used for sorting refer to the recommended build; entries without a recorded size appear last in either size order. Dates come from saved files, source records, and published updates; they do not always identify when a game was first created. The “Last 2 weeks” shelf covers November 8–22, 2026.

    “Link checked” confirms a reachable file. “Launch checked” confirms that a title screen, interface, or game scene rendered and was visually reviewed. “Controls checked” includes a short input check. These checks do not certify every level or ending. Some 3D games need another graphics check because the test browser could not create a WebGL context. Desktop games need their own supported computer. Unavailable entries remain visible so they are not lost from the collection.

    Favorites and recently played are stored in this browser. Archive updated 2026-11-22.
